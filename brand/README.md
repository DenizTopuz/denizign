# Denizign Brand

This directory is the source of truth for the Denizign brand identity.

The Denizign portfolio represents the personal brand of Deniz Topuz.

The central brand concept is:

**From complexity to clarity.**

## Brand documentation

Use these files for brand decisions:

- `brand-foundation.md` — positioning, personality and brand principles
- `colors.md` — approved colour system
- `typography.md` — typography rules
- `imagery.md` — product imagery and photography direction
- `motion.md` — motion principles

These files define the brand.

Do not create alternative brand rules elsewhere unless explicitly requested.

## Logo assets

### Original masters

`/brand/logo/original/`

This directory contains protected source files.

Never:

- edit
- redraw
- optimise
- recolour
- simplify
- overwrite

files in this directory.

### Website assets

`/brand/logo/web/`

This directory contains website-ready versions derived from the protected originals.

The website should use assets from this directory.

The official Denizign red is:

`#D7263D`

Logo geometry must always remain unchanged unless explicitly requested by Deniz.

## Brand consistency

Before creating or modifying visual frontend work, consult the Denizign design skill and design system.

Do not introduce:

- new brand colours
- additional fonts
- gradients
- alternative logo versions
- visual styles that conflict with the brand documentation

The goal is consistency, not visual variety.
